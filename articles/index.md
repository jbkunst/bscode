# Articles

### Interactive examples

Run each bscode application directly in the browser with Shinylive.

- [Basic
  navigation](https://jkunst.com/bscode/articles/basic-navigation.md):

  A minimal bscode app using familiar bslib navigation and nav_select().

- [Flight operations
  dashboard](https://jkunst.com/bscode/articles/flight-operations.md):

  Combine bscode with bslib cards, value boxes, Plotly, Leaflet,
  Reactable, and base R graphics.

- [Full-screen maps](https://jkunst.com/bscode/articles/maps.md):

  Run independent Leaflet maps in separate navigation panels and verify
  widget resizing.

- [Sidebar
  navigation](https://jkunst.com/bscode/articles/sidebar-navigation.md):

  Use the same bslib navigation workflow with a wider icon-and-label
  sidebar.

- [SQL console](https://jkunst.com/bscode/articles/sql-console.md):

  A VS Code-like SQL editor and results console backed by an in-memory
  SQLite database.

- [Themes and icon
  libraries](https://jkunst.com/bscode/articles/themes-and-icons.md):

  Test custom bslib themes and navigation icons from several R packages.
